## 2. Nhóm Đã Sử Dụng AI Vào Việc Gì?

1. **Tích hợp tính năng AI thực tế trong sản phẩm**:
   - Xây dựng **Chatbot AI Hỗ trợ Sinh viên FORUS** sử dụng SDK `@google/genai` (`gemini-3.8-flash`) chạy trên backend Express (`server.ts`) để giải đáp công thức Giải tích/Đại số, sinh đoạn code LaTeX và tư vấn dịch vụ tại Cơ sở 1.
2. **Hỗ trợ phát triển & Thiết kế**:
   - Hỗ trợ gợi ý cấu trúc component React + Tailwind CSS đáp ứng tốt trên cả điện thoại và máy tính.
   - Hỗ trợ tạo và hoàn thiện hình ảnh minh họa sản phẩm (Combo bảng vẽ điện tử, Flashcard công thức toán chống nước) và rà soát chính tả nội dung mô tả sản phẩm.
